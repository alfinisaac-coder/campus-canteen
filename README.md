# Campus Canteen Management System

A full-stack MERN web application designed to make campus canteen food ordering faster, simpler, and more organized.

## 📌 Project Overview

The Campus Canteen Management System allows students to browse the available food menu, search and filter food items, add items to a cart, place orders, and track their order status.

The admin can manage the food menu and handle customer orders through a dedicated admin dashboard.

## ✨ Features

### 👨‍🎓 Customer Features

- Browse campus canteen food menu
- Search for food items
- Filter food by category
- Add food items to cart
- Increase or decrease food quantity
- View cart total
- Checkout with customer details
- Place food orders
- View previous orders
- Track order status

### 👨‍💼 Admin Features

- Admin dashboard
- View total food items
- View total orders
- View pending orders
- View total sales
- Add new food items
- Delete food items
- View customer orders
- Update order status
